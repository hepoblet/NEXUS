# apps/

One folder per app. A folder holds everything that makes that app different from the others: its definition and its brand assets. Nothing here is code.

Planned shape (see the roadmap in the root README):
```
apps/<app>/
  app.json      name, package id, version, environment, flags
  icon.png      source image for every icon size
  splash.png    source image for the launch screen
```

Empty for now. The first definition arrives in roadmap step 3.
